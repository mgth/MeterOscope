# MeterOscope

Application de mesure sur image : ouvrez une photo ou capturez depuis une caméra, définissez l'échelle, mesurez.
Écrite en Rust avec egui/eframe. Interface en français.

## Lancer

```bash
cargo run --release -p meteroscope
```
